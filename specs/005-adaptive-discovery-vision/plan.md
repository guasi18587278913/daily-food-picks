# Implementation Plan: 多入口发现与视频复核

**Branch**: `feature/adaptive-discovery-vision` | **Date**: 2026-09-14 | **Spec**: [spec.md](spec.md)

## Summary

在现有采集函数内增加可配置的新模式，沿用统一候选与发布流程。先实现解析和复用，再接入有界发现计划，最后增加仅对文字不确定视频触发的画面复核。保留明确的旧模式回退，不增加读取入口权限。

## Technical Context

- 云端 JavaScript / Node.js 20.19，原有 CloudBase/wx SDK，原生小程序；前端不新增操作流程。
- 复用 `dfp_results` 的独立 recordType/键前缀存放缓存、来源与判断，不新增客户端可读集合。
- 当前函数 180 秒、512 MiB。视频最大 32 MiB、最多 10 分钟、六帧、最长边 512 像素、提取限时、临时文件 finally 清理。Linux FFmpeg 固定版本及摘要作为部署依赖，不能把本机 macOS 二进制当云端包。
- Node 行为测试；真实媒体、本地回放、真实模型、Linux 云端包与正式轮次分别报告。

## Constitution Check

需求和验收先行；整体接入与成本优化已授权，新增视觉费用已按每轮3次/每日0.50元/首验6次0.20元获准。所有外部请求先预留，未知结果不退款；旧工作者不能覆盖新缓存或发布。读取不触发收费，原始视频、密钥和私有审计不进客户端。高风险模块和最终实现独立审查；部署前提供确定源码、包、配置差异和实际结果。

## Project Structure

- provider.js：新接口适配、真实话题及有界视频定位信息。
- reuse.js：时效、版本、内容标识和单调时间的成功结果复用。
- discovery.js：有界任务、真实线索扩展、来源统计与候选归属。
- video.js：下载与抽帧，限制域名/协议/字节/时间/进程，清理临时数据。
- vision.js：图像输入、视觉证据校验和模型响应。
- vision-budget.js：人民币预算预留、已知用量结算及未知结果保留。
- content-review.js：文字/视觉判断复用、同帧拦截及视觉服务编排。
- runner.js：编排和持久化恢复；config.js/index.js/config/discovery.json 提供开关与装配。
- prepare-functions/check-package：生成配置副本、核对部署依赖与客户端隔离。

以上业务源均位于 `cloudfunctions/collectTick/lib/`，配置和脚本沿用原目录。

## Phase 1: Data and contracts

详见 [data-model.md](data-model.md) 和 [contracts/collection.md](contracts/collection.md)。

### 发现安排

1. 发现阶段默认最多花 06:00 18 次、常规轮 4 次 TikHub 请求，总轮次上限不变；到达上限或候选目标就转细查，记录未查任务。
2. 每轮至少一次新发现请求。固定词按日期轮换，元数据入口生成真实搜索或话题任务；无真实页面标识不调用话题。
3. 来源池最多 100 项，按已检查结果调整优先级，给长期未探索入口机会；无检查不能当失败。过期和连续失败来源降频。
4. 详情附带作品不增加发现请求，满足初筛后进入统一队列；本轮最多 40 篇，已处理顺序不重排，不无限递归。
5. 公开收藏必须有明确公开标志。来源统计只在后台，不向产品流程暴露实现字段。

### 复用

普通详情、作者、热点和灵感最多 6 小时；今日候选和接近门槛资料收紧至 1 小时。强制新发现不能被缓存替代。判断键包含规则、模型、标题正文和视频内容标识：通过/排除最多 7 天，不确定最多 1 天，服务故障不缓存成内容结论。缓存不改采样时间，写入需租约及时间比较。过期而无预算时记录缺口。

### 视频与费用

仅数字条件仍适用且文字 uncertain 的视频进入复核。只读真实公开 CDN，拒绝重定向、非 MP4、损坏或越界素材；FFmpeg 仅本地输入、禁止网络协议、有超时。六帧有序送入真正视觉模型，校验帧号及可见操作/配方证据。

TokenHub 的 youtu-vita 将于2026-10-15下线，改为仍维护的图像识别直接接口 `vita-video-3.0`，地址与参数见内部契约。当前公开单价输入1.2元/百万tokens、输出3.5元/百万tokens。传图、格式、延迟和计费需首验。视觉每轮最多3次、每天0.50元；首验最多6次/0.20元已获用户明确许可。

按直接接口总tokens上限16384及输出上限1024保守预留23245微元人民币；成功且实际用量合法时结算明确费用并释放未使用预留，失败或未知仍占额度。无收费模型自动回退。文字和视觉结果分别记录，只有合格视觉证据才能提升最终判定。

## Validation

先适配/缓存行为测试，再发现/恢复/留额，再视频与视觉边界。用同批候选验证重复请求减少且结果一致。最后补原安全与发布回归、生成副本、包检查、独立审查、真实模型首验及确定源码的上线包。正式轮次另行观察。

## Complexity Tracking

新增单一职责模块以避免把所有逻辑堆进 runner；复用现有存储和定时入口，不建新微服务。新增服务独立分账，不改写原数据请求额度。
