# 005 验证入口

先确认新工作树及功能指针。后台共享源/配置改变后执行 `npm run prepare:functions`。

1. Provider/Reuse：新结构、缺值、时效、内容改变、过期工作者和重复消费。
2. Discovery/runner：六入口、真实参数派生、候选去重和上限、留额与恢复。
3. Video/Vision：真实素材抽帧、资源边界、缺授权零调用、证据格式及费用结算。
4. 受影响的原安全/发布回归与 `npm run check:package:vision`；改前端才补类型检查。
5. 视觉首验另按已批准上限运行，核对当前模型/单价/服务状态，不借用旧实验余额。
6. 同批候选的复用前后对照，分别报告模拟、回放及实际费用。

上线前需要确定提交、Linux 依赖包、配置差异、独立审查与真实验证。没有真实模型与云端链路证据，不能仅凭骨架或本地助手看图宣称已解决自动视频判断。

视觉部署必须执行严格入口`npm run check:package:vision`；普通`check:package`允许未准备解码器的默认关闭模式，若包中已有解码器仍核对摘要。
