# Data Model: 文件归属与迁移记录

本功能不新增业务数据库。只维护文件和开发状态的约定。

| 对象 | 字段／约定 |
| --- | --- |
| 文件迁移项 | 原根、原路径、新路径、迁移前摘要、权限、是否有意编辑 |
| 共同规则 | 一份主文件、稳定位置、版本；工具入口引用，不复制 |
| 功能选择 | .specify/feature.json 的 feature_directory，属于本工作区；显式任务路径优先 |
| 交接记录 | 主责、源码状态、已完成任务、验证证据、剩余问题、下一步 |

约束：原路径必须唯一映射；目标存在不能覆盖；未说明的内容变化不能通过迁移验收；私有备份和原始响应不进入默认 Git 跟踪。

状态：待迁移 → 已移动 → 摘要通过 → 引用与入口通过 → 审查通过。任一步失败保留原始备份，不删除失败证据。
