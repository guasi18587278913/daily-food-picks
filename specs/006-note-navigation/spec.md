# Feature Specification: 查看原笔记

**Feature Branch**: `feature/note-navigation`

**Created**: 2026-09-14

**Status**: 进展见tasks.md

**Input**: 用户要求处理选题台跳转链接，已真机确认官方小程序短链接可打开一篇视频正文。

## User Scenarios & Testing

### US1 点击查看对应原笔记（P1）

有可靠入口的卡片提供“查看原笔记”，点击后通过微信确认进入对应内容。每篇笔记必须对应自己的入口，不能用首页或另一篇成功样本替代。

**Independent Test**：给定已确认对应关系的笔记与官方链接，列表、搜索、收藏三种展示均使用该笔记入口；真机核对目标内容。

1. 有已核对入口时点击，使用原链接，目标必须与卡片对应。
2. 用户取消微信确认时，不报故障、不改收藏、不自动复制。
3. 平台拒绝或链接失效时明确提示不可直达，不提供复制选项；不能把跳转请求成功当成正文展示成功。

### US2 缺少可靠入口时明确提示（P1）

暂无可靠入口的作品显示非交互文字“原文暂不可直达”。按用户最新要求，移除卡片复制入口和失败后的复制选项。

**Independent Test**：旧快照、未知/损坏/错绑链接、链接配置读取失败均可正常看选题并看到明确的不可直达状态，不写入剪贴板。

### US3 链接来源可追溯且无需逐轮改前端（P1）

链接与作品编号在服务端绑定；只有已核对的对应关系可用于跳转。新增链接不需要重新上传前端。目标是自动取得每篇官方入口；当前自动来源尚未验证，不能把手工导入和接口接线称为批量问题已解决。

**Independent Test**：核对来源、笔记编号与真实打开结果后导入；错绑、重复指向、未确认数据拒绝，未授权读取不泄漏链接。无效输入不能触发数据采集或模型调用。

### Edge Cases

- 官方短链接为不透明字符串，无法从字符串直接推断笔记编号。
- 不同笔记误用同一短链接、已确认入口被覆盖、旧客户端读取新字段。
- 外部来源存在QQ路径、猜测的微信路径或文字里的恶意链接，不能当作已验证微信入口。
- 平台安全提示、只到首页、用户取消、接口失败、重复点击。
- 已完成采集快照不可因补入口而改动正文、指标、推荐顺序或取数时间。

## Requirements

- FR001：可靠入口显示查看原笔记，未知入口显示非交互的原文暂不可直达；沿用收藏/搜索/排序/往期行为。
- FR002：每条跳转数据必须与对应作品编号绑定且有核对记录；不拼造官方短码，不从正文/模型输出提取入口。
- FR003：跳转由用户点击触发，取消无错误提示；失败只提示不可直达，不提供或执行来源链接复制。
- FR004：已发布笔记的链接可独立更新；不重新采集、不修改已发布快照来伪装新结果。
- FR005：旧客户端兼容，读取授权保持；只有本次返回笔记的入口能下发，读取过程不调用TikHub/视觉或新付费服务。
- FR006：错误/缺失链接不影响选题数据与封面返回，保留可观察状态。
- FR007：自动获取每篇官方入口需要实际证据；未知部分保持未完成，不能将一个测试视频的短链用到全部卡片上。

## Key Entities

- 已确认入口：笔记编号、官方短链接、核对时间、可选失效时间、对应关系确认。
- 入口目录：当前版本、最多100条已确认记录；超过上限拒绝写入，不删除历史记录冒充成功。

## Success Criteria

- SC001：同一已确认笔记在列表、搜索、收藏中跳到对应原文，至少一个真实已入库视频完成真机确认。
- SC002：取消、缺失、读取失败、错误绑定、并发更新及旧客户端场景不误跳或丢选题。
- SC003：读入口的新增数据库读取最多一次/请求，零TikHub及模型调用；补链接不改变已有快照。
- SC004：实际可直达覆盖率如实报告；自动批量来源未解决时不得声明全部完成。

## Assumptions and scope

用户已授权处理跳转问题；已知单篇官方短链的视频真机成功。成功样本对应身份由助手自行核实，不以用户逐篇提供链接作为自动化方案。用户进一步要求图文与视频分别核实自己的微信入口；已有图文mini_program_info.path需要原样验证，不能预设只有shortLink可用。未购买新服务、未改变采集/视觉预算。缺封面单独待修，本功能不改变采集策略或角色权限。

用户后续明确要求移除复制链接：本功能不再包含来源复制回退。该要求不涉及管理员的邀请码复制。

本规则在006新版部署时修订001的来源复制要求；旧版复制验收记录保留为历史事实。

## 2026-09-15 夜间交付范围

用户要求助手负责全部调试与上线，翌日只进入小程序验收。按这一完整交付授权，保留已验证官方外跳能力，同时增加“查看内容”：外跳尚不可靠时，可在选题台内阅读已采集正文、配图和视频。该页面标明来源及采集时间，不能冒充小红书原生页面；不恢复来源复制、不把受限外跳说成修复成功。

### US4 在选题台查看已采集内容（P1）

- 所有已发布选题的卡片提供“查看内容”；封面和标题也可进入详情。
- 详情读取必须经过当前用户授权，并确认该笔记已发布；不能通过笔记ID访问候选、未发布或其他任意记录。读取不调用TikHub、模型或写入数据库。
- 详情显示标题、作者、发布时间、采集时间、已取得的正文、最多20张配图及已有视频地址。只呈现已采集内容，不让AI补写正文；旧数据配图缺失、正文截断、媒体失效需明确提示。
- 仅在已有可靠外跳绑定时，详情页额外提供“前往小红书”。未知入口不再发起已证明受限的跳转。
- 前端不暴露采集密钥、原始API响应或判断内部记录。返回的图片和视频地址只允许既有来源CDN或该条已保存封面的临时云存储链接。
- 列表缺云封面时可使用已存的对应来源封面地址；不修改历史快照、推荐规则或用户收藏。

验收：已发布视频能读取正文并播放已有媒体，图文显示真实配图；候选ID、缺身份、停用用户拒绝；读详情零TikHub/模型/数据库写入；媒体失败不白屏；返回后收藏与列表状态保持。实际平台外跳限制仍单列，真机验收由用户明日完成。
