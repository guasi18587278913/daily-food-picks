# UI 状态契约：选题台首页

**Feature**: [spec.md](spec.md) · **Plan**: [plan.md](../plan.md)

本契约列出改版必须覆盖的页面状态。触发条件引用现有页面数据，行为和文案含义以 001 为准；本功能只规定呈现方式。截图核对时逐行记录结果。

| # | 状态 | 触发条件（现有页面数据） | 必须呈现 | 对应需求 |
| --- | --- | --- | --- | --- |
| S01 | 加载中 | `loading && !total` | 顶部控制可见；内容区显示加载提示，不闪现空状态 | FR-011 |
| S02 | 未开通 | `locked` | 锁图标、“这里为指定成员开放”、服务端返回说明、“重新查看”主按钮；不显示选题、数量、搜索和图片 | US4-1 |
| S03 | 等待首次更新 | `statusLabel` 为“等待首次更新” | 状态行中性状态点 | FR-011 |
| S04 | 整理中 | `statusLabel` 为“新选题整理中” | 状态行显示整理中，保留当前内容与日期 | FR-011 |
| S05 | 已更新 | `statusLabel` 为“已更新” | 绿色状态点 | FR-011 |
| S06 | 部分更新 | `statusLabel` 为“本轮部分更新”，`message` 或 `partialReason` 有值 | 琥珀状态点；轮次标题下浅橙说明块，文字不改成“完整” | US4-2 |
| S07 | 更新未完成／调用上限 | `statusLabel` 为“本轮更新未完成”或“本轮已到调用上限” | 状态行与说明块如实显示；保留上一轮内容 | US4-2 |
| S08 | 新一轮提示 | `newAvailable` | 深橙提示条“新一轮选题已更新 · 看看新灵感”，点击回到最新；不强制跳转 | US3-3 |
| S09 | 错误提示 | `message` 为读取失败文案且未锁定 | 说明块显示错误；旧内容保留 | FR-011 |
| S10 | 有选题的板块 | `board.count > 0` | 色标、名称、条数、规则、排序胶囊（当前项高亮）、左图右文卡片 | US1、US2-3 |
| S11 | 空板块 | 选题台或往期视图下 `board.count === 0` 且 `total > 0` | 一行：色标、名称、规则（可省略）、“本轮暂无”；无排序胶囊 | US2-1 |
| S12 | 三个板块都为 0 | 非搜索、非收藏视图，`!total` 且未加载中 | 统一空状态“等一轮新鲜灵感”与每日更新时刻；不重复显示三个空板块 | US2-2 |
| S13 | 搜索结果 | `mode === 'search'` 且 `total > 0` | 轮次标题为“某某的搜索结果”，说明“搜索已保存的全部轮次”；卡片同 S10 | US3-2 |
| S14 | 搜索无结果 | `mode === 'search'` 且 `!total` | “这次还没有找到”空状态与换词建议；清空按钮可用 | US3-2 |
| S15 | 收藏为空 | `mode === 'favorites'`，无收藏卡片和失效收藏 | “留住下一道创作灵感”空状态 | FR-009 |
| S16 | 收藏列表与失效收藏 | `mode === 'favorites'`，`favoriteCards` 或 `missingFavorites` 有值 | 已收藏卡片为浅橙收藏按钮；失效项为虚线行“这篇收藏暂时无法读取” + “取消收藏” | US3-4 |
| S17 | 继续查看／更早轮次 | `nextCursor`、`olderRounds`、`loadingMore` | 描边按钮“继续查看”（读取中禁用）；文字按钮“加载更早的轮次” | FR-011 |
| S18 | 页脚与复制弹窗 | 常驻页脚；复制成功后弹窗 | 页脚两行事实说明；弹窗确认按钮使用 `accentInk` | FR-007、US1-6 |

## 卡片字段

| 字段 | 来源 | 为空或未知时 |
| --- | --- | --- |
| 封面 | `thumbUrl` | 统一占位图形，尺寸不变 |
| 内容类型 | `typeLabel` | 图文 |
| 标题 | `displayTitle` | “打开原文看做法” |
| 作者 · 日期 | `author`、`publishedLabel` | “作者未提供”、“时间待确认” |
| 主数字 · 单位 | `big`、`unit` | “—”，不显示 0 |
| 对比说明 | `comparison` | 沿用现有文案，例如“作者参照不足，暂不计算倍数” |
| 收藏状态 | `favorite` | 未收藏 |
