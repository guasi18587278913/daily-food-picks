## 本地完成

- shared/source-navigation.js作为共享校验源，生成到前端和catalog；新工作树先执行npm run prepare:functions，不能手改副本。
- 单个服务端入口目录最多100条、一次导入最多20条，按版本事务合并；拒绝未确认、未发布笔记、重复短码指向不同笔记和过期版本。
- catalog只在返回非空笔记时读目录一次，只下发返回笔记的链接；状态轮询、轮次列表、空结果及拒绝请求不增读量。目录故障保留数据、封面与复制能力。
- 按用户最新要求移除来源复制：有有效绑定时只显示查看原笔记，无绑定显示非交互的原文暂不可直达。按原样shortLink发起，不猜path；取消静默，失败仅提示，不操作剪贴板，不把API成功当正文已展示。
- 独立审查发现并修复刷新竞态：用户点击旧“查看”按钮而描述刚被撤销时，不再自动复制；描述撤销走确认，笔记已移除只提示刷新。
